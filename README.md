# Personal Information Card

A small command-line Python program that collects a person's name, age, city, and hobby, then displays them in a simple text-based information card.

## Why use it?

- Demonstrates a simple Python class (`Person`) for grouping related information.
- Prompts for user input and formats the responses as a readable card.
- Runs with Python's standard library; no additional packages are required.

## Getting started

### Requirements

- Python 3

### Run the program

Clone or download this repository, open a terminal in the project directory, and run:

```bash
python "Personal Information Card.py"
```

If your system uses `python3` to run Python 3, use:

```bash
python3 "Personal Information Card.py"
```

Enter your name, age (as a whole number), city, and hobby when prompted. The program prints the information in a decorative card, for example:

```text
===========Information Card=========================================
             Name:     Alex
             Age:      29
             City:     Bristol
             Hobby:    Coding
```
